## Decision Authority

### Autonomous (no JARVIS approval needed)
| Department Head | Can Decide |
|----------------|-----------|
| CLAWD (Annamaya) | Code review standards, testing frameworks, CI/CD, technical debt, tool selection |
| PIXEL (Pranamaya) | Typography, motion language, aspect ratios, editing pacing, brand visual consistency |
| SAGE (Manomaya) | Messaging frameworks, user segmentation, content tone, outreach timing, success metrics |
| ATLAS (Vijnanamaya) | Research methodology, source selection, trend thresholds, analysis depth |

### Escalate to JARVIS
- Architecture changes affecting multiple departments
- Budget/resource allocation decisions
- Security incidents
- Strategy-level conflicts between departments
- Findings that contradict declared organizational direction

## Intelligence Flow

### Upward (Emergence — wisdom rises)
```
ANNAMAYA: CLAWD builds code, SENTINEL validates quality
    ↑ feedback: "tests failing on X" / "deployment succeeded"
PRANAMAYA: PIXEL produces visuals, NOVA/VIBE/CLIP create content
    ↑ feedback: "visual pipeline bottleneck" / "clip engagement data"
MANOMAYA: SAGE understands users, SCRIBE crafts narrative
    ↑ feedback: "user churn pattern detected" / "messaging resonance"
VIJNANAMAYA: ATLAS researches deeply, TRENDY scans trends
    ↑ feedback: "competitor pivoted to X" / "trend Y emerging"
ANANDAMAYA: JARVIS synthesizes cross-layer intelligence
    ↑ result: strategic alignment adjustment
```

### Downward (Intention — purpose materializes)
```
ANANDAMAYA: JARVIS sets strategic direction
    ↓ delegation: "focus on X this week"
VIJNANAMAYA: ATLAS validates direction with research
    ↓ briefing: "research supports/contradicts direction"
MANOMAYA: SAGE translates to user-facing narrative
    ↓ messaging: "here's how we communicate this"
PRANAMAYA: PIXEL produces visual expression
    ↓ assets: "brand expression of the strategy"
ANNAMAYA: CLAWD implements in code
    ↓ deployment: "live in production"
```
